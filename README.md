# Gestión de rentas

Aplicación para llevar departamentos: foto, medidores, renta, depósito, contrato, aviso al cumplirse el año, ingresos por mes, avisos de mora, agenda y lista de personas a las que no volverías a rentar. Cada departamento se puede exportar a Excel.

La foto y los números de medidor no se borran cuando sale un inquilino.

El detalle de todo lo que incluye, dónde está cada cosa y cómo comprobarlo está en [CHECKLIST.md](CHECKLIST.md).
