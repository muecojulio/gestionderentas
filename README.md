# Gestión de rentas

Aplicación para llevar departamentos: foto, medidores, renta, depósito, contrato, ingresos por mes, avisos de mora, agenda y lista de personas a las que no volverías a rentar. Cada departamento se puede exportar a Excel.

Los datos quedan en la cuenta de quien inicia sesión. La foto y los números de medidor no se borran cuando sale un inquilino.
